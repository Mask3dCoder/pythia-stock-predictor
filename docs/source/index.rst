Pythia Stock Predictor
======================

A professional-grade CLI tool for stock market prediction using machine learning algorithms.

Features
--------

- Multiple ML Models (ARIMA, LSTM, GRU, Ensemble)
- Technical Indicators (SMA, EMA, RSI, MACD, Bollinger Bands)
- Sentiment Analysis (VADER, TextBlob)
- REST API with rate limiting
- Interactive Dashboard (Streamlit)
- Cryptocurrency Data (CoinGecko)
- Forex Data
- Options Analysis with Greeks
- Fundamental Analysis
- Sector Analysis
- Market Breadth Indicators
- Pattern Recognition
- Anomaly Detection
- Trading Signals

Quick Start
-----------

Install via pip:

.. code-block:: bash

    pip install pythia-stock-predictor

Run the CLI:

.. code-block:: bash

    pythia --symbol AAPL --predict

Run the API:

.. code-block:: bash

    pythia-api

Run the dashboard:

.. code-block:: bash

    pythia-dashboard
