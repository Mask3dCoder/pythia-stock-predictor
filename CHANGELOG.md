## [1.0.0] - 2026-03-15

### Added

- **ARIMA Model**: Time series forecasting using AutoRegressive Integrated Moving Average
- **LSTM Model**: Long Short-Term Memory neural network for sequence prediction
- **GRU Model**: Gated Recurrent Unit for efficient sequence modeling
- **Ensemble Model**: Combined predictions from ARIMA, LSTM, and GRU with configurable weights
- **Technical Indicators**: SMA, EMA, RSI, MACD, Bollinger Bands support
- **Sentiment Analysis**: VADER and TextBlob integration for news sentiment
- **REST API**: FastAPI-based prediction service with secure API key authentication
- **Interactive Dashboard**: Streamlit-powered visualization for predictions
- **Data Collection**: Yahoo Finance and Alpha Vantage API integration
- **CLI Interface**: Command-line tool for data collection, training, and prediction
- **Test Suite**: Comprehensive pytest suite with 28 tests

### Fixed

- **Ensemble Logic**: Corrected prediction aggregation in ensemble model to properly weight individual model outputs
- **MAPE Calculation**: Fixed Mean Absolute Percentage Error calculation to handle zero values and improve accuracy
- **API Security**: Moved sensitive API keys from config to environment variables
- **Data Preprocessing**: Improved handling of missing values in historical data
- **Model Persistence**: Fixed model saving/loading for TensorFlow models

### Security

- **Environment Variables**: API keys now stored in `.env` file (referenced via `.env.example`)
- **API Key Authentication**: REST API endpoints secured with `X-API-Key` header
- **Git Ignore**: Comprehensive `.gitignore` to prevent accidental secret exposure
- **Input Validation**: Added validation for user inputs in CLI and API

### Infrastructure

- **CI/CD Pipeline**: GitHub Actions workflow for automated testing
- **Code Quality**: Ruff linter integration
- **Code Coverage**: HTML coverage reports configured

## Upgrade Guide

### Upgrading to v1.0.0

1. **Environment Variables**: Create a `.env` file based on `.env.example` and add your API keys
2. **Dependencies**: Run `pip install -r requirements.txt` to get the latest dependencies
3. **Configuration**: Review `config.yaml` for any new settings

---

## Migration from v0.1.0

```bash
# Backup your existing configuration
cp config.yaml config.yaml.backup

# Install new dependencies
pip install -r requirements.txt

# Set up environment variables
copy .env.example .env
# Edit .env with your API keys

# Test the installation
pytest
```
